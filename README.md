# سامانهٔ مرکز جامع سنجش، آموزش، توان‌بخشی و مداخلات بهنگام

این سامانه صرفاً یک ایده است. با توجه به چند سالی که به‌عنوان مدیر یکی از مراکز سنجش کار کرده‌ام، فکر می‌کنم این جریان کاری برای مدیریت کارها در این مراکز بهتر است.

دقت کنید هستهٔ ایده بر دو ستونه استوار است:

1. تیم علمی مرکز شامل درمانگران، آزمایندهٔ تخصصی و دیگر همکاران بتوانند با هم روی یک پروندهٔ دانش‌آموز کار کنند و فعالیت‌ها، تمرین‌ها و قالب‌هایی که برای جلسهٔ مداخله تهیه می‌کنند را به اشتراک بگذارند.
2. تقویم و نوبت‌گیری‌ها شکل بصری داشته باشند تا مدیریت نوبت‌ها ساده و با حداقل کلیک انجام شود.

سامانهٔ مدیریت کامل (CRM) مراکز سنجش و اختلالات یادگیری — مدیریت نوبت‌دهی، پروندهٔ دانش‌آموز، ارزیابی و مسیر بالینی — با دو بستر هم‌ارز: **میزی آفلاین‌فرست** (Node/Tauri روی خودِ مرکز) و **ابری** (Cloudflare Workers + D1)؛ فرانت‌اند ES Module خام (بدون bundler) و رابط کاربری کامل فارسی/RTL.

## سه بستر، یک کد

| بستر | مناسب برای | شرح |
|------|-----------|-----|
| **میز (پیش‌فرض مرکز)** | کلینیک بدون تیم IT | پوستهٔ Rust/Tauri + موتور محلی Node + SQLite؛ نصب آفلاین از پک USB، کار روی وای‌فای مرکز از موبایل |
| **ابری** | دسترسی از بیرون مرکز | Cloudflare Workers + D1 — همان باندل ورکر، همان رفتار |
| **Docker / سرور شخصی** | خود‌میزبانی | Node.js + SQLite درون کانتینر — با همان کد |

## نصب دسکتاپ و کار روی وای‌فای مرکز — به زبان ساده

1. **نصب:** فایل نصاب ویندوز (Setup.exe) را از صفحهٔ [Releases](../../releases) روی یک رایانهٔ مرکز نصب کنید. اینترنت لازم نیست.
2. **اجرای سرور محلی:** با باز کردن برنامه، یک سرور کوچک روی همان رایانه بالا می‌آید و همهٔ داده‌ها در SQLite روی خودِ مرکز می‌ماند.
3. **اتصال از موبایل و لپ‌تاپ:** برنامه نشانی شبکه را نشان می‌دهد (مثل `http://192.168.1.20:8080`). هر گوشی یا لپ‌تاپی که به همان وای‌فای وصل است، همان نشانی را در مرورگر باز می‌کند و نسخهٔ کامل برنامه را می‌بیند.
4. **چند کاربر هم‌زمان:** درمانگر با گوشی، منشی با لپ‌تاپ و مدیر با رایانهٔ میز، همه روی یک پایگاه دادهٔ مشترک کار می‌کنند؛ تقویم و پرونده‌ها برای همه لحظه‌ای به‌روز است.
5. **پشتیبان و به‌روزرسانی:** پشتیبان JSON درون‌اپ و drill بازیابی از دست‌نرفته است؛ نسخهٔ تازه را برنامه خودش چک می‌کند و از همان پنل نصب می‌شود.

اگر اینترنت مرکز قطع شود هیچ‌چیز از کار نمی‌افتد — ابر فقط برای هم‌گامی اختیاری بین چند مرکز و دسترسی از بیرون است.

## بستر میز: آفلاین‌فرست روی خودِ مرکز

- **پوستهٔ Rust/Tauri** با نگهبان بیرونی: راه‌اندازی موتور، ری‌استارت بک‌آف (۲/۵/۱۰ ثانیه با سقف)، پروب سلامت، چرخش لاگ.
- **موتور دولایه با پاریتی آزمون‌شده:** همان باندل ورکر ابر روی میز؛ smoke دوهاته با مجموعهٔ بررسی برابر (۲۸/۲۸) در هر دو حالت.
- **کار از موبایل روی وای‌فای مرکز:** بایند LAN + نشانی واقعی دستگاه در پنل نجات و بوت (`/api/system/lan`).
- **پک USB نصب آفلاین:** چیدمان تکرارپذیر با `npm run usb:pack`.
- **مرکز کنترل شبکه (CP):** توزیع بدون پورت ورودی — نود همیشه خودش می‌کشد؛ شش کانال (اعلان‌ها، گزارش KPI تجمیعی، محتوا، باگ‌وپاسخ، سلامت نود، خواندن قراردادی D1) با قانون طلایی «تجمیع در نود، فقط عدد در مرکز». مخزن جدا: `cp-repo`.

## وضعیت انتشار (نسخهٔ ۱.۲۷.۳۲)

- **تست:** ۲۹۴۴ آزمون سبز (Vitest) · **tsc strict:** صفر خطا
- **گیت‌ها:** smoke دوهاتهٔ موتور ۲۸/۲۸ · سازگاری D1 روی ۱۲۰ مایگریشن · بودجهٔ کارایی باندل · desktop-check (۱۶۸ چک)
- استقرار ابری: Cloudflare Workers واحد + D1 + cronهای زمان‌بندی (یادآوری‌ها، خلاصهٔ روز)
- فرانت: RTL کامل، تقویم جلالی، تم روشن/تاریک توکنی، skeleton لودینگ، موبایل‌فرندلی

## راه‌اندازی محلی (بستر ابری)

```bash
npm install                                         # wrangler 3.x (عمداً v4 نه)
npx wrangler d1 create center-system-db             # database_id را در wrangler.toml بگذارید
npm run migrate:local                               # مایگریشن‌ها روی D1 محلی
npm run bootstrap                                   # روز صفر — فقط حساب مدیر (manager/1234)
npm run dev                                         # http://localhost:8787
```

- ورود اولیه: `manager / 1234` (فقط محلی — در تولید با `bootstrap:remote` و رمز دلخواه بسازید).
- هویت توسعه: کلیک روی چیپ نام کاربر (هدر `X-Dev-Staff-Id`) — فقط با `ENV=development` در `.dev.vars`.
- تم: روشن/تاریک با کمترین انیمیشن · جستجوی سراسری: `Ctrl+K`.
- اعلان‌ها/بات: secrets محلی در `.dev.vars` (`BALE_BOT_TOKEN`, `BALE_WEBHOOK_SECRET`) — تولید با `wrangler secret put`.

## ساختار پروژه

```text
src/                  ← سورس TS لایه‌ای (core/domain/application)
worker/               ← ورودی دولایهٔ Worker + بک‌اند کامل + لایهٔ امتیاز
public/               ← پنل مدیریت (SPA بدون bundler) + assets
desktop/              ← پوستهٔ Rust/Tauri (نگهبان، نصاب، drill)
migrations/           ← تک‌منبع تغییرات اسکیما D1 (فقط additive)
scripts/              ← استقرار امن، باندل انتشار، موتور محلی، seed ها
docs/                 ← مستندات فارسی
```
