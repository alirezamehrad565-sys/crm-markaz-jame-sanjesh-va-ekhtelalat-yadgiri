# درون‌ریزی اکسل ()

ورود دسته‌ای اطلاعات تجمعی (مدارس، تقویم اجرایی کلر بوک) از فایل اکسل — با جریان «قالب → پر کردن → بازگذاری → بازبینی → ثبت».

## جریان

1. **قالب**: مدیر در همان صفحهٔ منو دکمهٔ «درون‌ریزی اکسل» را باز می‌کند؛ قالب خالی یا «داده‌های فعلی» (برای ویرایش) به‌صورت `.xlsx` دانلود می‌شود — شیت «داده» + شیت «راهنما»، راست‌به‌چپ.
2. **پر کردن**: فایل در اکسل پر می‌شود (تاریخ شمسی مثل `1404/07/01`، وضعیت با برچسب فارسی، ارقام فارسی/لاتین هر دو پذیرفته می‌شود).
3. **بازگذاری**: همان فایل در همان گفت‌وگو بازگذاری می‌شود؛ پارس با SheetJS سمت مرورگر انجام می‌شود (باندل ورکر سنگین نمی‌شود).
4. **بازبینی**: `POST /api/import/:entity/validate` وضعیت هر سطر را برمی‌گرداند: **افزودن / ویرایش / خطا** (با دلیل فارسی). سطر خطادار ثبت نمی‌شود؛ بقیه قابل ثبت‌اند.
5. **ثبت**: `POST /api/import/:entity/commit` ردیف‌های معتبر را در یک تراکنش upsert می‌کند و یک رکورد audit (`import.schools` / `import.clearbook_plans`) می‌نویسد.

## قاعده‌های کلیدی

- **کلید تشخیص ویرایش**: مدارس = نام مدرسه (نرمال‌شده)، تقویم اجرایی = عنوان فاز. نرمال‌سازی: ارقام فارسی→لاتین، ی/ک فارسی، فاصله/نیم‌فاصله بی‌اثر.
- **خانهٔ خالی در ویرایش = مقدار قبلی حفظ می‌شود** (در راهنمای قالب هم آمده است).
- حداکثر **۵۰۰ سطر** در هر فایل (`IMPORT_ROWS_MAX`).
- کد مدرسه یکتاست؛ تعارض با مدرسهٔ دیگر → سطر خطا می‌گیرد.
- «تا تاریخ» قبل از «از تاریخ» → خطا؛ تاریخ شمسی با بازگشت‌سنجی کنترل می‌شود (اسفند ۳۰ سال غیرکابیسه رد می‌شود).
- منبع حقیقت ستون‌ها فقط `registry.ts` است — هم سرور و هم ساخت قالب سمت مرورگر از آن می‌خوانند.

## دسترسی

| موجودیت | نقش‌ها | هم‌راستا با |
|---|---|---|
| `schools` | فقط مدیر | `POST/PATCH /api/schools` |
| `clearbook-plans` | مدیر + منشی | کلر بوک () |

## مسیرها

- `GET  /api/import/registry` — موجودیت‌های مجاز نقش فعلی + تعریف ستون‌ها (برای ساخت قالب/جدول پویا)
- `POST /api/import/:entity/validate` — `{ rows: [{ columnKey: value, … }, …] }`
- `POST /api/import/:entity/commit` — همان payload؛ خروجی `{ added, updated, skipped }`

## افزودن موجودیت تازه

1. ورودی در `registry.ts` (ستون‌ها، نقش‌ها، `listUrl` برای «داده‌های فعلی»).
2. تابع `validateXxxRow` + شاخهٔ commit در `service.ts`.
3. دکمهٔ «درون‌ریزی اکسل» در view همان منو: `openExcelImport({ entity: 'کلید', onDone })`.
