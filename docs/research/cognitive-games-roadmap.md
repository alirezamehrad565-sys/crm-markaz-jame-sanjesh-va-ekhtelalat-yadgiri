## ۳) خط تولید هر بازی تازه (ثابت — ۹ گام)

1. **انتخاب مرجع** — مخزن MIT/CC0 پیدا و خوانده می‌شود؛ مجوز در سرآیند فایل ثبت می‌شود.
2. **قرارداد** — یک `CONTRACT.md` برای زیراجنت: مکانیک، پاسخ کلاینت `{...}`، اهرم سختی، بانک، حس عدی، لحن §۲.
3. **ساخت موازی** — زیراجنت‌ها هم‌زمان: `kinds/<kind>.js` + `css-fragment.css` + `bank.mjs` (SQL) + `NOTES.md`.
4. **موتور** — در صورت نیاز برنچ عام تازه در `session.js` (الگوی `timedchoice`/`sequence`)؛ فقط یک‌بار.
5. **سرور** — `pure.ts` نمره‌دهی + فرمول‌ها، `stages.ts` مراحل/فیلتر/آستانه، `types.ts`، `registry-extra.ts` سنجه‌های موتور، `service.ts` سیم‌کشی.
6. **موتور شواهد** — `evidence.ts` نشانه‌های نوع‌بازی‌آگاه (در صورت نیاز نشانهٔ تازه).
7. **آزمون** — طلایی نمره‌دهی/مراحل/شواهد + e2e زنجیرهٔ کامل ارسال→گزارش + گیت پاکی ماژول.
8. **دروازه‌ها** — tsc صفر · vitest · bundle-smoke · perf-budget · node --check دارایی‌ها.
9. **بامپ + نشاندن** — نسخهٔ شش‌نقطه‌ای، CHANGELOG، seed SQL روی D1 عملیاتی، دیپلوی، راستی‌آزمایی مرورگری.

## ۵) شاخص‌های موفقیت برنامه

- **تعداد**: ۶ نوع‌بازی (۱.۲۵.۳۲) → ≥۹ تا پایان فاز ۲، هر کدام با بانک authored قطعی و پنج مرحله.
- **کیفیت**: هر بازی: طلایی‌تست نمره‌دهی + e2e زنجیرهٔ کامل + موتور شواهد فعال + آستانهٔ گذار proposed.
- **سرعت تولید**: خط تولید §۳ — هر بازی تازه ≤ یک روز کاری با زیراجنت‌های موازی.
- **پایبندی مجوز**: هر سرآیند فایل منبع+مجوز دارد؛ سند `oss-cognitive-games-review.md` مرجع بازبینی است.
