# رجیستری مبدأ ابزارهای بالینی (INSTRUMENT-SOURCES)

مستند ممیزی روان‌سنجی (۱.۲۷.۸۸): «هر ابزار از کجا آمده و وضعیت هنجار/باندهایش چیست».
این سند از خودِ محتوا تولید شده است — ستون «منبعِ ادعاشده» عیناً (verbatim) فیلد `source` بلوک JSON همان ابزار است؛ هیچ ادعایی بازنویسی، بهبود یا اضافه نشده است.

قرارداد ستون «وضعیت باند/هنجار»:

- **مستند** — برش/باند در متن منبع به مرجع استنادی گره خورده است.
- **کالیبراسیون داخلی** — بخشی از باندها/برش‌ها در متن منبع صراحتاً درون‌مرکزی خوانده می‌شود (کالیبراسیون داخلی، باند مرزی داخلی، تصمیم بالینی داخلی، «برش اولیه — کالیبراسیون با دادهٔ مرکز»). برچسب محافظه‌کارانه است: جزئیات در متن verbatim همان ردیف هست.
- **بدون مبدأ — نیازمند تأیید** — عدد هنجار/باند در متن منبع هیچ مرجعی برایش ادعا نشده است.
- **بدون باند/هنجار** — فرم ساختارمند/مصاحبه است و باند یا هنجار عددی ندارد (ستون `tool_norm` در DB عمداً NULL است).

مقادیر `tool_source`/`tool_norm` جدول `case_event_types` با مایگریشن `0126_tool_metadata_backfill.sql` از همین فیلدها پر شده‌اند و در مسیر sync محتوا (بلوک‌های JSON → `src/domain/clinical-engine/instruments.ts` → مایگریشن‌های محتوا) همین متن مرجع است.

قالب‌های `ce-*` خارج از باتری سه‌گانه بالا (وکسلر `ce-wechsler-w4-v1`، پروتکل‌های توان‌بخشی، پایش خانه، فرضیه‌نگار، جمع‌بندی‌ها و نظرسنجی‌ها) فیلد `source` در JSON باتری ندارند؛ `tool_source`/`tool_norm` آن‌ها NULL است تا ادعای منبعی جعل نشود. برای این قالب‌ها شناسنامه باید از طریق فرم‌ساز (شناسنامهٔ ابزار) توسط مرکز ثبت شود.
