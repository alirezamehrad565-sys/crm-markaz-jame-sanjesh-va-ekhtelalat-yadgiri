## شرح هر مایلستون

### فاز A — زنده‌کردن زنجیره (زیرساخت مشترک همهٔ بسته‌ها)
- **M1 (۱.۲۵.۰۷) بستر — بک‌اند خالص:** سه مایگریشن (`0087` payload بازی روی بانک تمرین، `0088` توکن/جلسه/دوز، `0089` منبع و پیوند پروب)؛ ماژول دامنهٔ `games` با موتور خالص (نمره‌دهی سروری، نردبان ۸۰/۶۰، دوز با مرز روز تهران)؛ API پرسنلی و عمومی؛ تزریق `addPathProbe` از موتور بالینی. گیت‌ها: تست موتور خالص، گاردهای سلامت رخداد، گیت توکن/نقش، idempotency پایان جلسه. بدون تغییر بوت.
- **M2 (۱.۲۵.۰۸) کودک:** صفحهٔ مستقل `/play` (لینک امضاشده از بات بله)، موتور رندر سبک، بازی گونوگو، دوز سمت سرور، پایان محترمانه، گیت‌های رفتاری فرانت (بدون تایمر/رتبه/فلاش، کاهش‌جنبش). راستی‌آزمایی مرورگری ایزوله با دادهٔ آزمونی.
- **M3 (۱.۲۵.۰۹) حلقهٔ درمان:** ویرایشگر payload در بانک تمرین (فرم دینامیک + پیش‌نمایش)، کارت «تمرین تعاملی» در پروفایل کودک (صدور/ابطال لینک، جلسات، تنظیم دوز)، نشان پروب خودکار در گزارش مسیر، گزارش هفتگی والد در بات، بازی خط عددی v1 (بازی دوم، بی‌صدا).

### فاز B — محتوای بی‌وابستگی به صدا (سریع‌ترین بازگشت)
- **M4 (۱.۲۵.۱۰) عدد کامل + والد:** مقایسهٔ کمیتی + فلش‌کارت فاصله‌دار حساب (اولین گونهٔ «تمرین هدایت‌شده»)؛ بستهٔ والد: ۵ درس روان‌آموزش + پروتکل خوانش گفت‌وگویی + تأیید دومضربه‌ای والد → پروب پایبندی.
- **M5 (۱.۲۵.۱۱) باتری هدف‌محور:** مسیرهای دغدغه (خواندن/نوشتن/ریاضی/توجه/رفتار/حرکتی)، نگاشت «هر ابزار یک اقدام» + گزارش فرم‌های کم‌اقدام برای تصمیم مالک، جمع‌بندی یک‌جمله‌ای پایان هر ابزار، توصیه‌گر v1 (پیشنهاد → تأیید درمانگر)، پرو ورود گونوگو به‌عنوان سنجهٔ عینی مسیر شناسایی توجه. این مایلستون مستقیماً درد «تعدد پرسشنامه» را درمان می‌کند.

### فاز C — صدا و بستهٔ خواندن (شواهد A)
- **M6 (۱.۲۵.۱۲) خط صدا:** اعلان R2 در wrangler، آپلود صدای فارسی توسط درمانگر (اعتبارسنجی MIME/حجم/مدت، نسخه‌بندی)، بازی واجی صوتی v1 (قافیه، واج آغازین/پایانی). مسیر خارجی موازی: ضبط استاندارد + بازبینی متخصص گفتار پیش از انتشار.
- **M7 (۱.۲۵.۱۳) فونیکس و خانه:** نگاشت حرف-صدا با ترتیب کتاب درسی + فلش‌کارت فاصله‌دار واژه‌های بسامد‌بالا + برنامهٔ خوانش جفتی روزانه با ثبت.

### فاز D — نوشتن و جلسه
- **M8 (۱.۲۵.۱۴) نوشتن فاز ۱ (بدون بازی):** برنامهٔ کپی و بازنویسی هدایت‌شده (حداقل ۲۰ جلسه — قاعدهٔ شواهد) + اسکریپت جلسهٔ شکل حرف + ثبت نتیجه.
- **M9 (۱.۲۵.۱۵) جلسه‌ها و قلم:** اسکریپت فعالیت برای بقیهٔ هدف‌های واژه‌نامه + بازی مسیر قلم به‌عنوان لایهٔ انگیزشی روی تمرین واقعی.

### فاز E — اثبات
- **M10 (۱.۲۵.۱۶ + عملیات) پیلوت چندخط‌پایه:** ابزار کوچک (پرچم خط پایه، خروجی CSV هر کودک) + اجرای عملیاتی با ۴-۶ کودک، شروع پله‌ای (≥۱ هفته فاصله)، معیار موفقیت از پیش مکتوب. خروجی: گزارش پیلوت. تا پیش از آن، حق ادعا صفر است.

## مسیرهای خارجی موازی (مالک مرکز)
