## ۱. نقشهٔ سفر — از لینک تا پایان

```
درمانگر: تجویز → مأموریت → لینک امضاشده (توکن ۲۵۶-bit، فقط-hash + jti، انقضای پایان-روز تهران/۱۲ساعت)
   │
والد: بازکردن لینک /m/:token
   ├─ expired/revoked  → «پیوند به پایان رسیده… پیام تازه دریافت می‌کنید»
   ├─ parent_pre       → نمای والد: درس کوتاه (متن واقعی از parent_copy.before بسته — U8/G3) + «گوشی را به کودک بدهید و کنارش بمانید»
   │     └─ parent_gate  → گیت والد («من مامان هستم» → تأیید) — گام ضدکودک، دوباره‌یابی امن
   ├─ child_active     → پخش‌کنندهٔ کودک (بازی) — §۳؛ جلسهٔ نیمه‌تمام = کارت خوش‌برگشتی «چند قدم مانده» (U7/G3)
   ├─ child_done       → کارت پایان با ستاره‌های مرحله + دعوت آرام به جلسهٔ بعد
   └─ parent_post      → پس‌گفت والد (شمار جلسهٔ هفته + پاسخ‌های امروز + جملهٔ فردا از parent_copy.after — U8/G3)
```

- رفرش در هر حالت = بازسازی همین صفحه از حالت سرور — کلاینت هیچ حالت اصلی ندارد («حالت فقط در سرور است»).
- جلسهٔ کسری با «آخرین فعالیت ۶ ساعت» جمع می‌شود؛ لینک تازه ادامهٔ همان جلسه است.
- noindex؛ CSP صفحهٔ کودک `default-src 'none'`؛ توکن هرگز hash نمی‌شود در لاگ.

## ۲. ماشین حالت ۱۴-حالته (`machine.js`)

```
IDLE → INSTRUCTION → (DEMONSTRATION | PRACTICE | READY) → FIXATION → STIMULUS
     → RESPONSE_WINDOW → INTER_TRIAL_INTERVAL → READY | PRACTICE | BREAK → … → COMPLETED
     + PAUSED · INTERRUPTED · INVALID        (ترمینال: COMPLETED / INVALID)
```

- گذار با جدول بسته — گذار نامجاز = استثنا؛ هر گذار تاریخ‌دار (`performance.now()-t0`).
- `INVALID` امروز هیچ مسیر ورودی ندارد (P3-2 — حالت مرده؛ تصمیم مستند در M3: یا زنده‌سازی یا حذف با بامپ نسخه).
- **مکث برگه** (`visibilitychange`): FIXATION/STIMULUS/RESPONSE_WINDOW/ITI/PRACTICE/READY → `PAUSED{from}` + انجماد sleeper/ساعت RT/تایمرهای موج؛ برگشت با `resumeTo`. INSTRUCTION/DEMONSTRATION/BREAK پوشش ندارند (P3-7 — اثر کم، فهرست G1).

## ۳. جریان داخل پخش‌کنندهٔ کودک (`session.js` — ارکستراسیون ۵-فازی)

| فاز | آنچه کودک می‌بیند | نکتهٔ قراردادی |
| --- | --- | --- |
| ۱. شناخت | کارت INTRO (نام/قانون/دکمهٔ بزرگ — فقط تمرین، G3) + آموزش بازیکن‌محور (`previewSteps`)؛ هر شش بازی تمرین تعاملی تا موفقیت با تکرار بی‌سرزنش | قدم گو ۱۰s / بازداری نوگو ۳s (پیش‌فرض بستهٔ jsPsych؛ لمس همه‌جای صحنه) |
| ۲. آماده | READY | گونوگو شاخهٔ touch_report طلایی است |
| ۳. اجرا | بلوک‌های پروتکل: FIXATION→STIMULUS→RESPONSE_WINDOW→ITI | بازخورد + سبد ستاره فقط train و فقط تمرین؛ پاپِ بازخورد بعد از مُهر پینت |
| ۴. استراحت | BREAK لمسی-محور (`break_min_ms`) | فقط بین بلوک‌ها |
| ۵. پایان | کارت خلاصهٔ پایان (debrief) — فقط تمرین | «دقت امروز تو٪» + «میانهٔ زمان لمس‌های درست»؛ قاعدهٔ دامنهٔ صفر |

شاخه‌های نمایش هر نوع (`kinds/*.js` + هوک‌ها) فقط ظاهر فازها را عوض می‌کنند؛ زمان‌بندی/ثبت همه در موتور مشترک است. پاسخ سرور `next-item` ساختار آیتم + فاز (`train|probe`) + پروتکل را می‌دهد؛ کلید پاسخ هرگز در هیچ پاسخ شبکه نیست.

## ۴. شبکهٔ پخش‌کننده — تک‌نقطه و idempotency

| endpoint | زمان فراخوانی | قرارداد |
| --- | --- | --- |
| `GET state` | ورود/رفرش | حالت کامل + پروتکل + مرحله |
| `POST start` | آغاز اجرا | توالی seed در `sequence_json` منجمد |
| `POST next-item` | هر آزمون | آیتم بعدی (بدون کلید) |
| `POST attempts` | هر پاسخ | `response_json` خام کامل + idem_key — دوبار‌ارسالی = بازخورد نخست |
| `POST finish` | پایان | خلاصه + مکث‌ها؛ validity/quality سمت سرور |
| `POST parent-gate` | گیت والد | با/بدون solve |
| `POST confirm` | تأیید پایانی | پیوست جلسه به مأموریت |

- خطای شبکه = یک retry ۱۲۰۰ms → **پنل آرام** («اشکالی نداره؛ هر وقت اینترنت آمد…» + تلاش دوباره = رفرش از سرور).
- idempotency سه‌لایه: `idem_key` UNIQUE + گیت سرورِ پاسخ دوم + یکتایی DB `(session_id,item_id)` — حتی رقابت هم دوبار نمی‌شمارد (پیام خام درایور امروز می‌تواند نشت کند — P2-2، رفع G1).
- نمره فقط سروری؛ هیچ مسیری برای نوشتن نمره از کلاینت نیست.

## ۵. تفاوت‌های شاخهٔ ارزیابی در همان جریان

- آموزش: نسخهٔ دستورالعمل ثابت کوتاه (`standard`) — تمرین تعاملی/سبد/بازخورد/نوار/ستاره صفر.
- بدون کارت debrief؛ پایان = کارت «تمام شد» خنثی.
- پروتکل ثابت §COGNITIVE_SPEC ۳.۲ (۴۰/۷۲ آزمون)؛ توالی seed فقط برای touch_report فعال است (P2-4 — رفع G1).
- چرخهٔ عمر همان است؛ هیچ شاخهٔ موازی وجود ندارد — «دو حالت از یک موتور».

## ۷. پذیرش جریان (هر تغییر نمایش/جریان باید سبز کند)

1. گشت مرورگری ۳۹۰×۸۴۴ (لمس) + دسکتاپ ۱۲۸۰ با **صفر خطای کنسول** — هر دو حالت تمرین و ارزیابی.
2. مسیر کامل: گیت والد → آموزش → آزمون → استراحت → کارت پایان → تأیید؛ رفرش وسط هر فاز = ادامهٔ درست از سرور.
3. دو-ارسالیِ عمدی یک پاسخ = یک رکورد؛ قطع شبکه وسط آزمون = پنل آرام و ادامهٔ جلسه از سرور.
4. لحن: هیچ متن سرزنش در هیچ وضعیت (لینت متن گیت‌دار)؛ کاهش‌جنبش fail-closed.
