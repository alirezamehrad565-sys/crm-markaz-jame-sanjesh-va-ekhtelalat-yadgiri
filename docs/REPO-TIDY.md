# برنامهٔ مرتب‌سازی مخزن

وضعیت پس از بازسازی ۱.۲۷.۳۲ — تاریخچهٔ تازه، ورک‌فلوهای خودکار و سندهای سبک.

## انجام‌شده

| کار | شرح |
|------|------|
| اتحاد شاخه‌ها | main و rust هر دو روی یک کامیت‌اند؛ هر انتشار فقط `merge --ff-only` از rust به main |
| تاریخچهٔ تازه | ۱۰ کامیت تماتیک با نویسندهٔ `sdt144` و تاریخ‌های اصلی؛ تاریخچهٔ قدیمی حذف شد |
| تگ‌ها | فقط سه تگ فعال (v1.27.22/23/24)؛ تگ‌های مرده و تکراری حذف شدند |
| دیپلوی خودکار | `cf-deploy.yml` با هر پوش مؤثر روی main اجرا می‌شود (بکاپ → مایگریشن → deploy → سلامت ×۳ → رولبک) |
| ریلیز دسکتاپ خودکار | `desktop-build.yml` با هر تگ `v*` نصاب NSIS فارسی + پک USB را می‌سازد و ریلیز draft می‌گذارد |
| داکر خودکار | `docker-publish.yml` با پوش main و تگ `v*` ایمیج چندمعماری به GHCR می‌فرستد |
| حذف پل منسوخ | `sync-main-to-rust.yml` پس از اتحاد شاخه‌ها حذف شد |
| README | بازنویسی ساده‌زبان: نصب دسکتاپ، سرور محلی روی وای‌فای مرکز، Docker و ابر |
| CHANGELOG | از ۲۵۰۹ خط به خلاصهٔ نسخه‌به‌نسخه رسید |
| آرشیو پولیش | سندهای POLISH به `docs/archive/` رفتند |

## قاعدهٔ ادامهٔ کار

1. هر تغییر روی rust با کامیت کوتاه (`feat:/fix:/chore:/docs:/polish:` + یک خط فارسی).
2. انتشار = بامپ نسخه در rust → دروازهٔ کامل محلی → تگ `v*` (نصاب دسکتاپ خودکار می‌آید) → `merge --ff-only` به main (دیپلوی ابر خودکار می‌آید).
3. پیام کامیت و بدنه کوتاه می‌ماند؛ جزئیات در CHANGELOG همان نسخه ثبت می‌شود.

## باقی‌مانده

- بازبینی دورهٔ سندهای `docs/legacy/` و حذف آن‌هایی که دیگر به کد فعلی اشاره نمی‌کنند.
- گذر فصلی روی `TODO`های کد و بستن موارد حل‌شده.
- اگر ریلیزهای دسکتاپ منظم شدند، فعال‌کردن کانال OTA خودکار (امضای updater با راز موجود).
