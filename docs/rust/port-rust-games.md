# ارزیابی پورت Rust — ماژول بازی‌ها (فاز ۶ · rust-f8)

پرسش فاز ۶: «ارزیابی پورت Rust ماژول‌به‌ماژول، شروع از games». این سند ارزیابی است، نه پورت — تصمیم با کارفرما.

## وضعیت فعلی بازی‌ها

- **محتوا**: هشت بازی HTML/JS خودکفا (corsi، stroop، flanker، nback، numline، scan، simon، span) به‌صورت باندل `games-bundle ۱.۱۶MB` که هم در اپ ابری و هم روی میز «همگام آرتیفکت» سرو می‌شود (rust-f5).
- **API**: مسیرهای کم‌مصرف `m/*` (آیتم بعدی، ثبت تلاش) + `api/games/*` روی همان Hono/TS مشترک — یک کد، دو اجرا (وب و میز؛ design.md §۲).
- **سرویس جدای میز**: بازی‌ها روی پورت دوم با همان D1 و توکن مشترک (gates engine:smoke و drill سفر الف).

## گزینه‌ها و برآورد

| گزینه | توضیح | برآورد تلاش | ریسک | جمع‌بندی |
|---|---|---|---|---|
| A — بدون پورت (وضع موجود) | بازی‌ها آرتیفکت وب می‌مانند؛ Rust فقط پوسته/چرخهٔ عمر | صفر | صفر | ✅ توصیه |
| B — پورت API بازی‌ها به Rust | بازنویسی `m/*` و `api/games/*` در workerd-Rust یا سرویس Rust جدا | ۳–۵ هفته + نگهداری دائمی دو پیاده‌سازی | نقض «هم‌ریشته بودن API با تولید» — هر تغییر بازی دو جا پیاده می‌شود؛ drift منطق امتیاز/تلاش | ❌ مردود |
| C — پورت موتور بازی‌ها به Rust/WASM | منطق انطباق/امتیازدهی به WASM | ۶+ هفته | اثبات هم‌ارزی نتایج بالینی دشوار؛ بازگشت آموزشی نزدیک صفر | ❌ مردود |

## استدلال توصیه A

۱) قید طلایی خط rust از روز اول: «هم‌ریشته بودن API با تولید» — پورت یعنی دو منبع حقیقت برای منطق آزمون بالینی. ۲) بازی‌ها راحت‌ترین بخش برای چرخش‌ناپذیری نیستند، بلکه **تنها بخشی هستند که رفتارشان موضوع پژوهشی است** (نُرم‌ها، دنبالهٔ انطباق) — دست‌زدن به پیاده‌سازی بدون ضرورت، اعتبار داده را به‌خطر می‌اندازد. ۳) گلوگاه عملکردی وجود ندارد (load:baseline پاس است؛ بازی‌ها سمت مرورگر اجرا می‌شوند). ۴) اگر روزی موتور محلی به Rust کامل مهاجرت کند (بند باز فاز ۶ در phases.md)، مهاجرت APIها باید **ماژول‌به‌ماژول با آزمون هم‌ارزی پشت سر هم** انجام شود و games آخرین ماژول است، نه اولین.

## مهاجرت آینده — اگر کارفرما حکم داد

ترتیب پیشنهادی پورت ماژول‌به‌ماژول (از کم‌خطر به پرخطر): `announcements/notifications` → `todos/waitlist` → `reports` → `screening` → `games (آخر)`. پیش‌نیاز هر ماژول: آزمون هم‌ارزی درخواست/پاسخ با بدنهٔ واقعی + پارالل‌ران یک هفته در یک مرکز پایلوت. هیچ‌کدام بدون حکم صریح کارفرما شروع نمی‌شود.
