# راه‌اندازی نخست و اتصال ابر (rust-f7)

مکمل `design.md` §۵ (سینک ترکیبی). این ماژول «محیط نصب و توتوریال» را با یک ویزار اولین-اجرای نقش‌محور و پنل «اتصال ابر» کامل می‌کند: کاربر میز بدون دانش فنی، آدرس ورکر و اعتبار نود را یک‌بار وارد می‌کند و اتصال همان‌جا آزمون می‌شود.

## جریان کاربر

1. **بوت نخست میز**: پوستهٔ Rust موتور محلی را بالا می‌آورد و پیش از ناوبری، `__DESKTOP_SHELL__=true` و `__DESKTOP_FEATURES__={tutorial:true,setup:true}` را به صفحه تزریق می‌کند (lib.rs).
2. **ویزار (۴ گام)**: خوش‌آمد → اتصال ابر (آدرس ورکر + کد نود + کلید نود + «آزمون اتصال») → توکن Cloudflare (اختیاری + «آزمون توکن») → پایان. «رد کردن» همیشه مجاز است — سامانه کامل آفلاین است و اتصال ابر هیچ مسیری را قفل نمی‌کند.
3. **پس از پایان ویزار**: توتوریال نقش‌محور (rust-f3) خودکار شروع می‌شود؛ در app.js ویزار همیشه پیش از تور است.
4. **تنظیمات**: بخش «اتصال ابر» — وضعیت، «آزمون دوبارهٔ اتصال» (با راز ذخیره‌شده)، «ویرایش اتصال» (ویزار دوباره)، «پاک‌سازی اتصال» (حذف رازها + فراداده).

## دو اعتبار جدا — هرگز قاطی نمی‌شوند

| اعتبار | برای چه | به کجا می‌رود | کجا ذخیره می‌شود |
|---|---|---|---|
| کد نود + کلید نود (`node_code`/`node_key`) | سینک ترکیبی: pull اعلان/کتابخانه/بسته‌ها و push گزارش/خطا/سلامت (`/node/pull·push`) | **فقط به ورکر خودِ مرکز** | مخزن امن (Credential Manager ویندوز) از طریق فرمان Rust `desktop_secure_store` |
| توکن API Cloudflare (اختیاری) | فقط آزمون اعتبار توکن حساب کلادفلر | **فقط به `api.cloudflare.com/client/v4/user/tokens/verify`** | مخزن امن، همان مکانیزم |

توکن CF برای سینک **لازم نیست** — سینک با کلید نود کار می‌کند (طراحی §۵). فیلد توکن صرفاً پاسخ به درخواست کارفرما برای «فضای گذاشتن توکن کلادفلر» است؛ توکن هرگز به ورکر ما، لاگ یا هیچ سرور واسطی ارسال نمی‌شود.

## ثبت نود از سمت ابر (پیش‌نیاز)

مدیر اپ ابری: `POST /node/register` (فقط-مدیر، با audit_log) → `node_code` و کلید `nk_live_…` که فقط یک‌بار نمایش داده می‌شود → همان دو مقدار در ویزار میز وارد می‌شود. چرخش/ابطال: `/node/rotate-key` (سیاست CP-6: کلید کهنه بی‌درنگ باطل) و `/node/revoke`.

## امنیت

- رازها هرگز در localStorage یا فایل پروژه نیستند؛ اگر مخزن امن پوسته در دسترس نباشد، fallback محلی با نشان صریح `insecure_fallback=true` و هشدار در تنظیمات استفاده می‌شود.
- آدرس ورکر فقط `https` (استثنا: `http` فقط برای 127.0.0.1/localhost) — اعتبارسنجی در کد.
- هر دو آزمونگر timeout هشت‌ثانیه‌ای با AbortController دارند و هیچ مسیری throw خام نمی‌کند (خطای نرم + پیام فارسی — حکم م۲۱۰).
- فهرست سفید دادهٔ سینک در کد هر دو سمت است (rust-f4) — این ماژول فقط اتصال را مدیریت می‌کند، داده‌ای به ابر نمی‌فرستد.

## ساختار ماژول (هم‌الگوی src/tutorial)

- `flags.ts` — SETUP_FEATURE + کانال پوسته (`shellFeatureEnabled`)؛ در وب هر دو خاموش.
- `state.ts` — فرادادهٔ اتصال (کلید `cloud_conn_v1`) + قرارداد SecureStore + پل `__TAURI_INTERNALS__` + fallback نشان‌دار.
- `verify.ts` — `verifyCloudNode` (GET `/node/pull?domains=announcements&limit=1` با هدرهای X-CP-Node-Code/Bearer — عین پاکت m1.2) و `verifyCloudToken` (verify endpoint کلادفلر).
- `dom-build.ts` + `types.ts` — لایهٔ DOM باریک و پوستهٔ modal (بدون lib DOM در tsconfig).
- `wizard.ts` — منطق ۴ گام؛ متدهای next/back/skip/finish/testNode/testToken روی handle برای آزمون.
- `run.ts` — `maybeRunSetup` (هوک app.js) و `cloudSetupSection` (هوک settings.js).

## آزمون‌ها و گیت‌ها

۳۸ آزمون تازه در `src/__tests__/cloud-setup-{state,verify,wizard,gate}.test.ts`: قرارداد انبار/مخزن امن، رفت‌وبرگشت رکورد، fallback ناامن، دو آزمونگر با fetch مک (ok/401/شبکه/۵۰۰/بدURL/توکن نامعتبر)، ناوبری و پایان/رد شدن ویزار با فِیک DOM، پیش‌پر از رکورد، و گات وب (false و بدون اثر جانبی). معنای گات توتوریال از AND به «فلگ استاتیک یا کانال پوسته» تغییر کرد و آزمون آن به‌روز شد (تغییر مستند در کامیت f7).

گیت‌ها (۱۴۰۵/۰۸/۲۱): tsc صفر · vitest **۲۳۹۶/۲۳۹۶ (۲۱۱ فایل)** · build:client ✓ (چانک lazy تازه) · desktop:check ۲۱/۲۱ · engine:smoke ۱۹/۱۹.

## محدودیت‌ها

- کامپایل Rust (keyring) در CI انجام می‌شود (cargo در سندباکس نیست) — `desktop-build.yml`.
- فرم ویزار بدون CSS اختصاصی است (کلاس‌های معنایی cloud-*)؛ پوستهٔ Tauri استایل پایه را می‌گیرد — پوسته‌بندی بصری نهایی با طرح گرافیکی کارفرما.
- ویزار Escape-کلید ندارد (فقط دکمهٔ «رد کردن») — محدودیت ثبت‌شده.
